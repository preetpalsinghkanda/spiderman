# Spider Man - Brand New Day

this website based on Spider Man : Brand New Day
i made the whole website using GSAP (GreenSock Animation Platform) 
i recently learned GSAP from youtube (all thanks to sheryians coding school), so i made this project to practice my skill and understand animations better.

## Live URL 

`https://spiderman-topaz.vercel.app/`

> **Note:** please wait 10 sec after opening the live url for the best experience.
> this website is designed only for PC/Desktop and it's not responsive for mobile devices.

## Teck Stack 
- React JS
- GSAP
- Tailwind CSS
- Lenis
- HTML
